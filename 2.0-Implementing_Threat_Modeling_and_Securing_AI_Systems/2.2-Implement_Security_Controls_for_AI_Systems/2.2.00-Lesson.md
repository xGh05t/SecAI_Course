
# 2.2 Implement Security Controls for AI Systems

> [!IMPORTANT]
> **Exam Objectives**
> - 2.1 Given a scenario, use AI threat-modeling resources.
> - 2.2 Given a set of requirements, implement security controls for AI systems.

Securing AI systems takes more than just basic cybersecurity—it's about putting specialized controls in place, too. You might use model-specific controls and set up model guardrails to keep your AI working as intended and steer it away from risky decisions. Using prompt templates, along with gateway and interface controls, helps manage interactions and limits how the AI can be accessed or used. It's also important to regularly test all these security controls to make sure they're effective and adapt them as new threats emerge.
