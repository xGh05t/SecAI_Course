
# 4.1.2 Activity: Classify AI Life Cycle for a Use Case

You are a Security Auditor reviewing how security is handled across the AI lifecycle.

You will interact with two AI roles:

**AILifeCycleMentor** – guides you through each lifecycle phase and answers your security‑related questions.

**AuditReviewer** – helps you record your findings for each phase and evaluates your responses.

Start with AILifeCycleMentor, who begins in the Design phase. Ask about:

- The main security control(s) in that phase
- Any security gap(s) or risk(s)
- At least one improvement you would recommend

When you are ready to move on, clearly say that you are done with the current phase (for example: *"I’m done with Design. Please describe the next phase."*). You can also return to an earlier phase at any time by naming it (for example: *"I have another question about the Deployment phase."*).

After you have reviewed all phases (Design, Data Collection and Preparation (DataPrep), Model Development (ModelDev), Deployment, and Operations), open the AuditReviewer chat. AuditReviewer will prompt you to summarize, for each phase:

- Main Security Control
- Identified Security Gap (Y/N, and description if yes)
- Improvement Recommendation

You may respond phase by phase or provide all phases in a single, structured message.
