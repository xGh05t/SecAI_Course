
# 4.2.3 Model and Data Poisoning (Video Transcript)

## 1. Introduction to AI and Model Poisoning
AI helps the world run from healthcare to communication to
finance, but in order to rely on it, we have
to be careful that attackers don't tamper with it.

## 2. Methods of Model Poisoning
Any attack that corrupts an AI model is considered model
poisoning.
Most commonly, models can be poisoned before or during training
by manipulating the data training set.
Attackers can inject malicious or mislabeled data which will affect
the model's behaviour, therefore poisoning the model.

## 3. Example: Self-Driving Car
For example, imagine an AI powered self driving car.
What if in its training data, photos of dogs were
mislabeled with speed limit 70 mph.
Now the car thinks that seeing a dog means speed
up to 70 mph instead of slowing down.

## 4. Post-Training Model Poisoning
Models can be poisoned after training is complete too, like
if a model source code is modified.

## 5. Importance of AI Security
Let's go back to the self driving car.
Maybe the car was trained correctly on good data, but
if the source code gets modified, it will follow bad
instructions.
Attacks like these can make AI behave in ways we
don't expect.
That's why protecting against model poisoning is a crucial part
of AI security.
