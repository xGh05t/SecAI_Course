
# 3.2 Apply Data Security Controls for AI Security

> [!IMPORTANT]
> **Exam Objectives**
> - 1.2 Explain the importance of data security in relation to AI.
> - 2.4 Given a scenario, implement data security controls for AI systems.
> - 2.5 Given a scenario, implement monitoring and auditing for AI systems.

Keeping AI data secure is a top priority in any organization working with intelligent systems. To safeguard sensitive information, data security controls like strong authentication and access restrictions are essential. Encrypting AI data—both while it's stored and as it moves across networks—is a key step in protecting it from leaks or unauthorized access. Alongside these measures, adopting solid data safety practices helps ensure your AI remains trustworthy and your organization's valuable information stays protected.
